# ChordiggerApp
### 現在はα版です
## 概要
コード進行から楽曲を探索するWebアプリです。  
カノン進行が大好きだったので、同じコード進行のまだ見ぬ曲をガチャのように一曲ずつランダムに抽出してdigできたら面白そうだなというアイデアから作りました。  
Songle APIを利用しています。

## 現状の制約
- UI・機能ともに大幅に変更される可能性があります。
- キーの変更に対応していません（Cメジャーのみ）
- カノン進行、小室進行、王道進行以外に対応していません
- 動画をページ内の埋め込みで再生できません
